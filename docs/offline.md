# Offline and installing the app

Case Constructor needs no server: everything — the 3D view, the case
builder and its geometry engine, the fonts of the labels — runs in your
browser. After the first visit the browser keeps a copy of the whole app,
so it opens and builds cases with no network at all.

- **Install it** like an app: in Chrome or Edge the install button in the
  address bar (or *Install app* in the menu); on an iPhone or iPad, Safari's
  *Share* → *Add to Home Screen*; on Android, *Add to Home screen* or
  *Install app*. It opens in its own window, without the browser's bar.
- **Updates come by themselves.** When a new version is published, the app
  fetches it in the background and reloads to it the next time you return
  to it. Your case is kept on every change, so the reload loses nothing.
- Your cases and presets stay in this browser, as before (see
  [Presets and project files](presets.md)); save a project to a file to
  move it to another device.
