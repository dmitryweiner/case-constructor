# Export and printing

The **STL export** card has three tabs:

- **Body** — the body alone, turned with its opening up.
- **Lid** — the lid alone, lying on its outer face with the skirt up.
- **Both** — body and lid side by side in one file, 10 mm apart. The 3D view
  shows this layout while the tab is selected.

Every file comes already oriented for printing without supports.

**Resolution** — segments per quarter of every rounded corner in the file
(12, 24, 48, 64; default 24). The preview always uses 12.

Below the button the panel shows the outer size, the mesh check (a
watertight mesh is required) and any warnings. Export is blocked only by a
broken mesh, an empty part or a part larger than 400 mm.

**View** (top bar): *Lid* — closed, lifted off the case, or hidden;
*X-ray* — see through the walls.
